

# Species Information

## Units and Data in the JSON files:

mw:             [g/mol] Molecular Weight of Species
hf298:          [kJ/mol] ΔHf°, Stnadard Enthalpy of Formation a 298.15 K (25 degC)

"thermo_ranges" contains polynomial coefficients for the species.  This version of the code uses NASA7 format, but I may expand to other things in the future.

"transport_properties" contains things for calculating viscosity, and thermal conductivity.
